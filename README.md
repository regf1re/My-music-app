# Музыка — Android музыкальный плеер

Локальный музыкальный плеер для Android, написанный на **Kotlin** с интерфейсом на **Jetpack Compose**. Проект ориентирован на воспроизведение музыки, хранящейся на устройстве, и включает дополнительные инструменты для работы с текстами песен, эквалайзером, плейлистами и статистикой прослушивания.

> **Статус проекта:** в разработке. Возможности и совместимость отдельных функций зависят от версии Android, устройства, доступности аудиосессии и текущего состояния исходного кода. Перед публикацией релиза рекомендуется выполнить сборку и тестирование на реальном устройстве.

## Возможности

### Воспроизведение музыки

- Поиск и отображение аудиофайлов, доступных приложению на устройстве.
- Фоновое воспроизведение через отдельный сервис.
- Управление воспроизведением через системную медиасессию и уведомление.
- Поддержка режимов воспроизведения:
  - по порядку;
  - повтор всего списка;
  - повтор одной песни;
  - случайный порядок.
- Пауза при отключении или отсоединении аудиоустройства — если настройка включена.
- Возможность пропуска участков тишины — если функция поддерживается используемой версией Media3 и аудиоформатом.
- Переходы между песнями с эффектом crossfade, если функция активирована и корректно работает на устройстве.

### Библиотека и плейлисты

- Просмотр локальной музыкальной библиотеки.
- Сортировка по названию, исполнителю, дате добавления и длительности.
- Плейлисты и управление списками песен.
- Избранные композиции и дополнительные сведения о треках.
- Отображение метаданных: название, исполнитель, альбом и длительность, если эти данные доступны в аудиофайле или медиатеке.

### Синхронизированные тексты песен

- Загрузка и отображение синхронизированных текстов в формате `.lrc`.
- Отдельные компоненты для логики текста и его визуального отображения.
- Редактор LRC для создания и корректировки временных меток.
- Переход к соответствующему месту песни по нажатию на строку текста, если это предусмотрено текущей реализацией экрана.
- Дополнительное оформление экрана текста, включая фоновые GIF-ресурсы из `src/main/assets`.

Для синхронизации тексту нужны корректные временные метки, а воспроизводимая песня должна соответствовать текстовому файлу. Подробности приведены в разделе [Работа с текстами песен LRC](#работа-с-текстами-песен-lrc).

### Эквалайзер и визуализация

- Экран эквалайзера.
- Подключение эквалайзера к аудиосессии плеера.
- Обработка аудиоданных для получения спектральной информации, используемой визуализатором.
- Визуализация аудио в интерфейсе.

Доступность системного эффекта эквалайзера зависит от устройства и реализации аудиодрайвера. Если эффект недоступен, интерфейс не может гарантировать изменение звучания на каждом устройстве.

### Дополнительные функции

- Таймер сна для остановки воспроизведения.
- Статистика прослушивания: время воспроизведения, количество запусков, история и рейтинги.
- Статистика по годам, если накоплены соответствующие данные.
- Сведения о песнях и обложках.
- Настройка масштаба интерфейса.
- Сохранение пользовательских настроек между запусками приложения.

Состав функций и доступность отдельных элементов могут меняться по мере разработки.

## Технологии

- **JSON** — формат сериализации статистики прослушивания.
- **Gradle** — сборка проекта.

## Сборка и запуск

### 1. Получение проекта

Клонируйте репозиторий:

```bash
git clone https://github.com/regf1re/My-music-app.git
cd <ПАПКА-ПРОЕКТА>
```

### 2. Открытие в Android Studio

1. Запустите Android Studio.
2. Выберите **Open** и укажите корневую папку проекта — ту, в которой находятся `settings.gradle.kts` и `build.gradle.kts`.
3. Дождитесь завершения Gradle Sync.
4. Установите необходимые Android SDK, если IDE предложит это сделать.

**Важно:** ZIP с исходниками каталога `src/main` сам по себе не является полным Android-проектом. Для сборки необходимы Gradle-файлы, Gradle Wrapper и остальные файлы проекта. Если они отсутствуют в репозитории, добавьте их из рабочего проекта.

### 3. Сборка APK

В Android Studio выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

Либо в терминале из корневой папки проекта выполните:

На Windows:

```powershell
.\gradlew.bat assembleDebug
```

На macOS/Linux:

```bash
./gradlew assembleDebug
```

Готовый debug APK обычно появляется по пути:

```text
app/build/outputs/apk/debug/app-debug.apk
```

Путь может отличаться, если конфигурация сборки была изменена.

### 4. Установка на устройство

Подключите устройство с включённой USB-отладкой и выполните:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Можно также установить APK через Android Studio.

## Работа с текстами песен LRC

LRC — текстовый формат, в котором строки песни снабжаются временными метками.

Пример:

```text
[ti:Название песни]
[ar:Исполнитель]
[00:12.50]Первая строка
[00:16.20]Вторая строка
[00:20.00]Третья строка
```

В этом примере первая строка должна активироваться примерно на 12,5 секунде воспроизведения, вторая — на 16,2 секунде и так далее.

### Рекомендации

1. Используйте временные метки в формате `[мм:сс.сс]`.
2. Проверяйте, что текст относится к нужной версии аудиозаписи.
3. Учитывайте вступление, тишину в начале и возможные отличия в длительности ремастеров или концертных версий.
4. Сохраняйте резервную копию текстов перед массовым редактированием.
5. Если строки переключаются слишком рано или поздно, исправьте временные метки в редакторе.

Конкретное место хранения LRC-файлов и правила их поиска зависят от реализации `Lyrics.kt`, `LrcEditor.kt` и `PlayerViewModel.kt`.

## Разрешения Android

В `AndroidManifest.xml` объявлены следующие разрешения:

| Разрешение | Для чего используется |
|---|---|
| `READ_MEDIA_AUDIO` | Доступ к аудиофайлам на Android 13 и новее |
| `READ_EXTERNAL_STORAGE` (до API 33) | Чтение аудиофайлов на старых версиях Android |
| `FOREGROUND_SERVICE` | Запуск фонового сервиса |
| `FOREGROUND_SERVICE_MEDIA_PLAYBACK` | Фоновое воспроизведение на версиях Android, где требуется это разрешение |
| `POST_NOTIFICATIONS` | Отображение уведомлений на Android 13 и новее |
| `WAKE_LOCK` | Поддержание необходимого состояния устройства во время воспроизведения |
| `MANAGE_EXTERNAL_STORAGE` | Широкий доступ к общим файлам; требует особого внимания к правилам Android и Google Play |

Разрешение в манифесте не означает, что доступ уже предоставлен: приложение должно корректно запросить runtime-разрешения и обработать отказ пользователя.

`MANAGE_EXTERNAL_STORAGE` является специальным разрешением с ограничениями на распространение через Google Play. Перед публикацией проверьте, действительно ли приложению нужен широкий доступ ко всем файлам. Если достаточно чтения аудиомедиатеки, предпочтительнее использовать подходящие API медиатеки Android.

## Хранение данных

В коде используются локальные хранилища Android, включая `SharedPreferences`.

Известные области данных:

- настройки интерфейса — файл настроек `settings`, ключ `ui_scale` используется для масштаба UI;
- настройки воспроизведения — в том числе поведение при отключении аудиоустройства и пропуск тишины;
- статистика — сохраняется в JSON в локальном хранилище приложения;
- дополнительные пользовательские данные — в зависимости от конкретных классов и функций.

Очистка данных приложения через настройки Android может удалить сохранённые настройки, статистику и другие локальные данные. Перед такой очисткой экспортируйте важные тексты и сделайте резервную копию данных, если они нужны.

## Диагностика проблем

### Gradle Sync завершается ошибкой

- Проверьте JDK: проект настроен на Java 17.
- Проверьте установку Android SDK Platform 34.
- Убедитесь, что Gradle Wrapper и версии плагинов соответствуют конфигурации проекта.
- Сначала устраните первую ошибку в Build Output: последующие сообщения могут быть её следствием.

### Приложение не видит музыку

- Проверьте, предоставлено ли разрешение на чтение аудиофайлов.
- Убедитесь, что на устройстве действительно есть локальные аудиофайлы, индексируемые медиатекой Android.
- Проверьте поведение на целевой версии Android и после отказа в разрешении.
- Не путайте локальные файлы с музыкой, доступной только внутри другого приложения или облачного сервиса.

### Музыка останавливается в фоне

- Проверьте состояние уведомлений и разрешения фонового сервиса.
- Убедитесь, что приложение корректно создаёт и освобождает `MediaSession`.
- Проверьте системные ограничения батареи и режим энергосбережения на устройстве.
- Повторите тест с выключенным экраном и после сворачивания приложения.

### Эквалайзер не влияет на звук

- Поддержка системного эквалайзера может различаться между устройствами.
- Проверьте, что аудиосессия создана и `EqualizerManager` подключён к её ID.
- Сравните поведение на другом устройстве или с другим аудиовыходом.
- Убедитесь, что громкость и настройки эквалайзера не выставлены в нейтральное положение.

### Текст песни не синхронизируется

- Проверьте формат и временные метки LRC.
- Убедитесь, что приложение нашло именно нужный текстовый файл.
- Сравните временные метки с фактическим началом вокала.
- Проверьте поведение при перемотке, паузе и переходе к другой песне.

### Сборка падает из-за `mutableIntStateOf`

Если компилятор сообщает `Unresolved reference: mutableIntStateOf`, проверьте импорт в соответствующем Kotlin-файле:

```kotlin
import androidx.compose.runtime.mutableIntStateOf
```

Убедитесь также, что Compose Runtime корректно подключён через Gradle. Не добавляйте импорты наугад: ориентируйтесь на конкретный файл и сообщение компилятора.
